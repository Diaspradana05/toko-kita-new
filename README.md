Toko Kita

Toko Kita adalah aplikasi e-commerce frontend yang dibuat menggunakan React. Project ini memiliki alur belanja mulai dari mencari produk, melihat detail produk, menambahkan ke cart dan wishlist, hingga checkout dan melihat riwayat pesanan.

Fitur

* Katalog, pencarian, filter, dan sorting produk
* Detail produk dan pilihan varian
* Cart dan wishlist
* Login dan registrasi
* Checkout dengan voucher
* Riwayat pesanan
* Responsive design

Tech Stack

* React
* React Router
* Vite
* Context API
* CSS
* DummyJSON API
* LocalStorage

Catatan

Project ini dibuat sebagai project frontend untuk pembelajaran dan portofolio. Data produk menggunakan DummyJSON API, sedangkan data akun, cart, wishlist, dan pesanan disimpan di localStorage.
